# Sample Data

This folder contains sample datasets for testing the carbon-aware scheduler.

## 📁 Files

### `energy_data_historical.csv`
Historical carbon intensity data with the following columns:
- `timestamp` - Date and time of measurement
- `region` - Datacenter region (e.g., IN-WE, IN-SO, NL)
- `carbon_intensity` - Carbon emissions in gCO₂/kWh
- `solar_cloud_pct` - Solar energy availability (cloud coverage %)
- `wind_speed` - Wind speed in m/s
- `temperature` - Temperature in °C

### `energy_forecast_models.pkl`
Pre-trained machine learning models for carbon intensity forecasting.
- Contains models for each region and target variable
- Used by both Streamlit and FastAPI versions

### `cloud_schedule_future_optimal.csv`
Example output - optimized job schedule generated by the system.

## 🚀 Usage

### With FastAPI + React
```bash
# From the root directory
cd frontend
npm run dev
# Then upload files through the UI at http://localhost:3000
```

Upload:
1. `energy_data_historical.csv` as the historical CSV
2. `energy_forecast_models.pkl` as the trained model

### With Streamlit
```bash
cd streamlit
streamlit run app.py
# Upload files through the sidebar
```

## 📊 Generating New Data

To generate your own sample data:
```bash
cd streamlit
python generate_sample_data.py
```

This will create new CSV files with synthetic carbon intensity data.

## 🔧 Data Format Requirements

Your CSV must include these columns:
- `timestamp` (datetime)
- `region` (string)
- `carbon_intensity` (float, gCO₂/kWh)
- `solar_cloud_pct` (float, 0-100)
- `wind_speed` (float, m/s)
- `temperature` (float, °C)

Additional columns are allowed but not required.
